# PC 游戏启动

`GameLaunch` 是连接 Win32 控制器前执行的预任务，目前仅向国服官服资源开放。
在 MXU 的任务列表中添加并启用「启动 PC 游戏（国服官服）」，配置：

- 游戏程序：`Endfield.exe` 的绝对路径，不加引号。
- 官方启动器：可选。可以填写安装根目录 `Launcher.exe` 的绝对路径，也接受版本目录下的 `Games.exe`；留空时自动从 Windows 安装注册信息发现官方启动器。
  已有通过核验的 `Games.exe` 时，无论该项是否填写都会直接复用现有进程。

同时启用「游戏设置」时，将其排在「启动 PC 游戏」前面。
MXU 的普通前置程序无需再直接启动 `Endfield.exe`，避免重复拉起。
该预任务不会自动添加到既有任务列表。

程序先检查是否已有 `Endfield.exe`，有则跳过全部启动步骤。
否则查找正在运行的 `Games.exe`；没有时优先使用手动配置的官方启动器路径，未配置则从 Windows 安装注册信息自动发现，再打开已核验的官方启动器并按进程状态等待就绪。
使用同一个进程句柄查询实际映像路径、验证有效 Authenticode 签名和允许的签名者证书 SHA-1 指纹，
再通过 `STARTUPINFOEXW` / `PROC_THREAD_ATTRIBUTE_PARENT_PROCESS` 创建游戏。
PID 动态获取，工作目录是游戏目录，不修改游戏文件。

证书允许列表对应国服 1.6.3 的 Launcher 规则。证书轮换后应核实并更新允许列表；
不能降级到只校验文件名。国际服及渠道服需要独立核验启动器和证书规则。

本机国服 1.6.3 已验证不带额外游戏参数也能通过来源检查、SDK 初始化并创建窗口。
因此不提供游戏启动参数配置。上述游戏业务规则由 MaaEnd 处理，MXU 无需修改。

创建游戏进程成功后预任务返回，由 Client 继续等待并连接 Win32 控制器。
启动步骤失败时返回失败，不主动关闭游戏或官方启动器。
