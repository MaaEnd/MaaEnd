# 通知模板变量

在通知的标题、正文、Webhook 请求体中，可以使用以 `{{变量名}}` 表示的模板变量，发送时会被替换为实际值

## 变量列表

| 变量 | 说明 |
| --- | --- |
| `{{time}}` | 时间 HH:mm:ss（如 14:03:05） |
| `{{date}}` | 日期 yyyy-MM-dd（如 2026-08-27） |
| `{{datetime}}` | 日期时间 yyyy-MM-dd HH:mm:ss（如 2026-08-27 14:03:05） |
| `{{task_name}}` | 任务显示名（如 🔑自动切换账号；自动从任务入口解析，取不到时回退当前节点名，仍查不到则显示原文） |
| `{{task_status}}` | 任务状态（如 失败） |
| `{{duration}}` | 执行耗时（如 1m23s） |
| `{{controller}}` | 控制器名 |
| `{{resource}}` | 资源包名 |
| `{{title}}` | 本次通知标题（渠道配置中可引用；未配置时使用默认标题） |
| `{{body}}` | 本次通知正文（渠道配置中可引用；未配置时使用默认正文） |

## 使用方式

- 模板变量可直接写在通知标题、正文，以及 Webhook 的 URL / 请求头 / 请求体中
- `{{title}}` / `{{body}}` 用于在**渠道配置**的标题/正文里引用本次通知预填的内容；未使用时，渠道标题/正文默认为本次通知的标题/正文
- 未识别的 `{{变量名}}` 原样保留，不影响发送

## 注意

- 通知中的换行可用 `\n`（反斜杠 + n）表示，会自动转换为真实换行
- {{datetime}} 以及 {{time}} 显示的时间是发送通知的时间，`{{duration}}` 任务耗时从首个任务启动开始计时，发送通知时截止并计算时间
