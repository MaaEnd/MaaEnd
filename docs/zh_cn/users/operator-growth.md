# 培养干员

「🌱培养干员」是独立任务，根据游戏内培养总览显示的材料缺口，为指定干员刷取协议空间材料。每场领奖后重新检查需求，自动选择下一种缺少的材料；不执行干员升级、技能升级或武器强化。

本文依据当前培养干员任务实现编写，更新于 2026 年 11 月 12 日。

## 与协议空间任务的区别

| 任务 / 模式 | 刷取依据 | 任务配置 |
| --- | --- | --- |
| 协议空间：按次数刷取 | 指定关卡和执行次数 | 手动选择关卡、奖励和次数 |
| 协议空间：目标库存 | 设定物品的目标库存 | 填写需要保有的材料数量 |
| 培养干员 | 指定干员在培养总览中的材料缺口 | 选择培养干员和领取方式 |

## 使用方式

1. 在游戏中确认账号已开放培养总览，目标干员显示的材料需求符合预期，且所需协议空间关卡已解锁。
2. 在 MaaEnd 中添加「🌱培养干员」任务；单独运行此任务即可，不需要同时添加「⚔️协议空间」。
3. 选择「培养干员」，配置「领取方式」及理智不足时的处理方式。
4. 按需设置「执行周期(游戏时间)」「选择队伍」和「自动战斗设置」，然后运行任务。

培养干员任务每次只处理一名干员，不读取目标库存选项，也不提供刷取次数上限。它根据培养总览中材料图标下方的红色数量识别不足，不计算具体缺口数量；后续刷取持续到扫描未发现不足、理智策略无法继续或流程异常结束。

培养干员和协议空间是两个独立任务，各自选择执行周期和任务选项；在协议空间任务中设置的目标库存或次数不会成为培养干员任务的结束条件。

## 可配置选项

| 选项 | 行为 | 默认值 |
| --- | --- | --- |
| 执行周期(游戏时间) | 运行任务时检查勾选的星期；未勾选当前游戏日则跳过 | 周一至周日全部勾选 |
| 选择队伍 | 「默认」沿用当前队伍，也可指定 01 至 07 号队伍 | 默认 |
| 培养干员 | 从当前配置的干员名单中选择目标，管理员同时兼容男女头像 | 佩丽卡 |
| 领取方式 | 「优先双倍领取」或「单倍领取」；培养干员任务固定领取奖励，不提供仅战斗不领奖的选项 | 优先双倍领取 |
| 理智不足时 | 「结束任务」或「使用限时药剂恢复」 | 使用限时药剂恢复 |
| 使用几天内 | 使用限时药剂时，可选全部、10 天内、7 天内、3 天内或 1 天内 | 3 天内 |

执行周期使用运行 MaaEnd 的设备本地时间，以凌晨 04:00 为游戏日分界。它在任务开始时判断是否执行，不会按勾选日期自动启动任务。

领取方式和限时药剂规则沿用协议空间的实现，选项在培养干员任务中单独设置。「使用几天内」仅在选择「使用限时药剂恢复」时显示，限定可使用的限时药剂范围，不包含无时限药剂。

「优先双倍领取」会尝试使用理智消耗许可。若领奖时理智不足，按所选策略尝试恢复后仍未补充理智，才会回退到不使用许可的单倍领取；单倍仍无法领取时结束。若入场前已理智不足且无法按配置恢复，则直接结束，不会先进入战斗再回退。「单倍领取」不使用许可。

## 执行流程

1. 先检查执行周期；允许执行时打开干员界面，等待顶部入口区域稳定后检查培养总览；找到入口则进入，每次进入前重置列表滑动计数。
2. 将左侧干员列表回到顶部，按头像寻找目标干员，再用右侧姓名确认选中对象。
3. 依次检查「干员等级」「技能与天赋」「武器等级」三个分页；当前画面没有识别到不足时，每页最多再短滑一次检查。任一画面发现不足就先刷该材料，不会先扫描完全部分页。
4. 通过材料图标白名单和数量区域的红色判断不足，点击材料弹窗中的协议空间来源。
5. 按材料类型选择入场流程，复用现有编队、战斗和领奖逻辑。
6. 单场领奖成功后退出并返回培养总览，重新检查缺口，再决定下一场刷什么。

同一材料仍不足时会继续刷取；满足后按分页与画面中的识别顺序查找下一项，不按缺口比例排序。

## 关卡选择与结束条件

| 材料来源 | 入场规则 |
| --- | --- |
| 干员经验、干员进阶、技能提升、武器进阶 | 选择第五级，按弹窗中的物品名称设置 A/B 奖励；第五级未解锁时结束 |
| 钱币、武器经验、六类高危材料 | 直接进入来源指向的关卡，不重新选择等级或切换 A/B 奖励 |

完成本轮三个分页的检查且没有识别到白名单材料不足时，任务结束。这里的结束只表示当前扫描范围内未识别到不足，不保证培养材料全部备齐。理智不足且无法按配置继续领取奖励、目标关卡未解锁或战斗失败时，也会结束；培养干员任务不自动重试失败战斗，也不会在第五级未解锁时自动改刷低级关卡。

干员页稳定后仍找不到培养总览入口时，会提示账号可能尚未开放该功能或入口识别失败，并结束培养任务。

目标干员或材料来源无法识别时，流程可能识别超时退出，不能视为培养材料已经备齐。

## 当前范围

- 只补充能够通过协议空间获取、且已加入图标白名单的材料，不处理其他来源的培养材料。
- 只检查当前配置覆盖的分页区域和滑动范围；检查结束不代表所有培养条件都满足。
- 每次返回总览都会重新选人、检查材料，避免连续刷取已经不再短缺的材料；单场奖励仍可能超过实际缺口。
- 干员选项、培养总览入口及材料来源识别已配置简中、繁中、英文、日文和韩文；这不代表各语言均已完成实机验证。
- 任务配置允许 Win32 前台、三种 Linux 控制器、ADB、CloudADB 和 PlayCover。移动端总览的头像、材料模板和 ROI 覆盖位于 `assets/resource_adb/`，由 ADB、CloudADB 和 PlayCover 共用；资源共用不代表这些控制器均已完成实机验证。
