## 1. 定位到的真正卡点：`PhotoIcon.png`

终端页三张委托卡片的「可前往」判定链是：

```
Check<委托名>Text（OCR 委托名）
  └─ Check<委托名>Icon（TemplateMatch EnvironmentMonitoring/PhotoIcon.png，阈值 0.8）
       └─ Check<委托名>GoToMissionText（OCR「前往任务」，ROI 相对上面那个图标）
```

也就是说：**一张 19×15 的小图标 `PhotoIcon.png` 决定整张卡片能不能点「前往任务」**。
上游模板在网页画面上全图最佳相似度只有 **0.623**（阈值 0.8），所以三张卡全部过不了门，任务永远停在终端页。

## 5. 下一个要处理的模板

```

[JumpBack]SceneMapLayerSwitchToMain     （MapLayersOther/Main.png + 黄色 ColorMatch）
[JumpBack]__ScenePrivateMapZoomOut      （白色减号 ColorMatch，实测 ROI 内白像素 0）
```

（在某个节点的 `anchor` 字典里）还是上游漏了定义；确认后再取「传送锚点」的图标做模板。
