# 悬浮球隐藏（方案 B）· 2026-10-21

## 结论

**已实现并验证。** 游戏内检查结果：`matched=2, visible=0, initRan=52, styleTag=true` —— 球的两个 DOM 节点都在，但已不可见。

## 为什么不能只注入一次

点「开始游戏」后，云端会**新开一个标签页**接管游戏画面。只在原标签注册
`Page.addScriptToEvaluateOnNewDocument` 的话，新标签页完全不受影响——第一次实测就是这个现象：
启动时注入成功（`matched:0`），进游戏后检查变成 `matched:2, visible:2, initRan:0`。

## 实现

`~/maaend/web/linux/homesrv/hide_cloud_ball.py`，三种模式：

| 模式 | 作用 |
|---|---|
| 默认 | 对当前所有 endfield 页面各注入一次（init script + 立即执行） |
| `--check` | 只报告：`matched / visible / initRan / styleTag` |
| `--watch` | 常驻，每 2s 扫一遍 CDP 目标列表，**新标签页出现就自动注入** |

注入内容做三件事：
1. 插 `<style>`：`[class*="hbU_7F"],[class*="e4MbkW"]{display:none!important}`；
2. 对已存在的节点直接设 `display:none`；
3. `MutationObserver`（childList + attributes:class/style）+ 每秒兜底 —— React 是"先插节点再设 className"，只盯 childList 会漏。

class 是构建哈希，匹配不到时退化为几何判断（左上角 120×150 内、20–90 px 的 fixed/absolute 方块）。
