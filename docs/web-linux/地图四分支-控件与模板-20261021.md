## 2. 图层切换：控件在，差的是「黄色高亮」

`SceneMapLayerSwitchToMain` 是 **And 三个条件**：

1. `MapLayersOther.png`（39×32，ROI 左下）
2. 上一步框内**黄色** ColorMatch（count 10）
3. `MapLayersMain.png`（27×25）

实测第 1、2 条都不成立，第 3 条 0.953 成立 → 整条 And 失败。

**原因**：`MapLayersOther.png` 模板里左侧带一条**亮黄色竖条**（表示“另一层/当前层”的选中高亮），
网页端同一位置图标形状一致但**高亮条是灰白、不是黄色**（见 `cmp-layers.png` 右列）。
所以这不是“控件不存在”，是**高亮配色不同**。

网页端这个「分层」控制实际长这样：左下角 **`◀◀◀` + 文字「首墩内部」**（见 `crop-badge2.png`），
点箭头即回到上一层（主地图）。

## 3. 缩小：控件在，只是被禁用了——不要改

`__ScenePrivateMapZoomOutWhite` 的 ROI `[1225,423,26,26]` 是**绝对坐标**，正好落在地图右边缘的缩放控件上：

| 按钮 | 位置 | 底色 | ≥200 亮像素 |
|---|---|---|---|
| "+" | (1236,398) | 白圈 | **148** |
| "−" | (1237,424) | 深灰圈 + 浅灰减号 | **2** |

地图打开时就是最小缩放，所以 "−" 变灰——上游用“白 ≥150 像素”表达的正是**“还能继续缩小”**这个语义，
网页端表现一致。**这条分支不需要新模板，也不需要调阈值。**

## 4. 区域总览：模板没问题，卡的是界面状态

`MapOverviewEnter` 绿幕感知后 **0.992**，按钮就在右下角 (1046,641)（见 `cmp-mapoverview2.png`：左=上游，中间绿块是遮罩；右=网页，显示“地区总览”）。
所以 AutoEssence 卡 `__ScenePrivateMapOtherAreaEnterMapOverview` **不是模板/资源问题**，是那一刻**不在“有地区总览按钮的地图页”**（或前一节点把界面留在了别处）。

## 5. 结论：要不要新模板

| 项 | 判断 | 要做的事 |
|---|---|---|
| 地图识别 InMapAny | 好（0.959 / 0.998） | 无 |
| 图层切换 MapLayersMain | 好（0.953） | 无 |
| 图层切换 MapLayersOther | **网页高亮不是黄色** | 需要网页版：见 §6 |
| 缩小 ZoomOut | 控件存在，禁用态语义正确 | 无 |
| 地区总览 MapOverviewEnter | 好（0.992） | 无 |
| 传送成功 WorldMenu | 待取“传送后”画面 | 暂不动 |

**所以：上游是最新的（v2.35.0-beta.1），这批失败不是“没同步上游”，也不是“控件不存在”；
真正不适用网页端的模板只有 `MapLayersOther`（黄色高亮条）和之前已修的 `PhotoIcon`。**

## 6. 模板设计（图层切换）

**方案 A｜网页版 `MapLayersOther.png`（推荐，最省事）**
- 裁片：从地图左下角图标位 (31,605) 取 39×32（已存 `tpl-MapLayersOther-web.png`，是放大 6 倍的预览）
- 改动：去掉黄条依赖 → 覆盖 `SceneMapLayerSwitchToMain` 为 **And(MapLayersOther_web, MapLayersMain)**，删掉黄色 ColorMatch
- 风险：图层按钮在“已选中/未选中”两种态下亮度不同，可能需要两张模板（Selected / Normal）

**方案 B｜认徽标文字（最稳，抗配色变化）**
- 用 OCR 认左下角 **「首墩内部」**（ROI 约 [140,530,180,60]）→ 命中后点它上方的 `◀◀◀`（约 (196,545)）
- 优点：文字不随主题变色；缺点：别的分层地图文案不同（如「四号谷地地下」），需要用正则 `^.*(内部|地下|B\d).*$`

**方案 C｜不动这条分支**
- 它只是“从分层地图回主图”的兜底；如果任务的目标锚点本来就在当前层，这条分支不命中也不影响。
- 但要注意：`AnchorWithPick` 的 next 里四条全不命中时，节点会一直重试到超时（20 s）——这才是 AutoEssence/环境检测耗时的来源。
