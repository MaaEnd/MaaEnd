# AutoCollect 采集路线生成器

在地图上框选采集物，生成一条 AutoCollect 路线并登记到任务中；已登记的路线可在同一页面查看，改选采集点后重新生成或删除。从项目根目录运行：

```powershell
uv run autocollect-route
```

服务仅监听 `127.0.0.1`，默认端口 `8780`（被占用时顺延），启动后自动打开浏览器；`--port PORT` 指定首选端口，`--no-browser` 仅启动服务。

采集物与传送点数据读取 `tools/zmdmap/data/collect_points.json` 与 `teleport_anchors.json`，传送入口名读取 `tools/pipeline-generate/SceneTeleport/anchors.json`。采集物的类型表（名称、图标、采集动作、产物分类）与点位高度由 zmdmap 的 `collect_points` 数据集生成，本地数据缺少这些字段时执行 `uv run zmdmap generate --only collect_points` 重新生成。排序与路线展开依赖 navmesh 包 `assets/resource/model/map/navmesh/base.nav.gz`。

地图前端与寻路查询复用 [MapNavigator](../MapNavigator/README.md)：地图交互、工具条、状态栏以及路线与运行时展开的绘制均与路径编辑器一致，navmesh 查询使用同一个后端模块。本工具仅包含采集业务：`route_builder.py` 负责排序并生成路线，`route_reader.py` 读取已登记的路线，`registry.py` 按路线登记表生成任务注册，`server.py` 提供接口，`web/` 为页面。

## 使用

1. 在左侧卡片顶部选择四号谷地或武陵，再选择 `稀有采集物` 或 `常规采集物`。两类路线采集的物品互不重叠，列表与地图仅显示所选类别，切换类别时清空选择。主产物属于养成材料（菌、黯石、多齿叶等）的归入稀有，其余归入常规，任务物品不列出。
2. `已有路线` 列出当前地图该类已登记的路线（产物图标、名称、采集点数），带 `特殊结构` 标记的路线含生成器不会产出的结构，悬停可查看具体内容。单击打开，见[修改已有路线](#修改已有路线)。
3. `采集物` 按产物列出当前地图该类采集物（图标、挖掘标记、已选数量、已有路线覆盖的点数 / 本图点数）。复选框控制该类是否显示，搜索框按各语言名称筛选；隐藏某类时同时取消其已选点。
4. 在地图上框选采集物。缩小时采集物显示为按类别着色的圆点，放大后显示为带图标的圆形标记，已选标记外圈为琥珀色，已有路线采集的点外圈为绿色；悬停时状态栏显示名称、坐标与所属路线。
5. 点击 `生成稀有路线` 或 `生成常规路线`。采集顺序按步行距离确定，详见下文；排序期间状态栏显示已规划的段数。同一批点再次生成时复用已计算的距离。
6. 右上角列出路线 id、路线文件、起点传送点、采集点数、运行时寻路段数与产物。生成后自动按运行时语义展开整条路线，粉色线即 `MapNavigateAction` 实际行走的路径，并给出运行时路点数与步行总长。
7. `复制路线文件` / `复制 path` 仅复制内容；`写入任务` 先列出将新建与修改的文件，确认后写入，写入后自动打开新路线。

地图操作：

| 操作 | 说明 |
| --- | --- |
| 左键拖动 | 框选正在显示的采集物；按住 `Shift` 追加到已有选择，按住 `Ctrl` / `⌘` 从已有选择中移除 |
| 左键单击 | 切换单个采集物的选中状态 |
| 右键或中键拖动 | 平移视角；按住空格或 `Alt` 时左键拖动同样平移 |
| 滚轮 / `+` / `-` | 缩放；工具条右侧依次为放大、缩小、自适应（有路线时框住路线，否则框住已选点或整张底图） |
| `Ctrl` / `⌘` + `A` | 选中当前地图所有正在显示的采集物 |
| `Ctrl` / `⌘` + `Z` | 撤销选择；`Ctrl` / `⌘` + `Shift` + `Z` 或 `Ctrl` / `⌘` + `Y` 重做；切换地图、类别或打开、关闭路线时清空记录 |
| `Delete` / `Backspace` | 移除全部所选采集物 |
| `C` | 复制所选采集物的坐标，每行一个 `[u, v]`，格式与路径编辑器一致 |
| `Esc` | 依次取消正在绘制的选框、收起路线预览、关闭已打开的路线、清空选择；工具条上的黄色提示给出 `Esc` 与 `Delete` 此刻的作用 |
| `清空显示` | 工具条按钮，一次收起路线预览、关闭已打开的路线并清空选择 |

## 修改已有路线

单击 `已有路线` 中的一条打开它：地图按路线文件原样绘制全部导航段，分层坐标换算到底图，并逐段按运行时语义展开；起点传送点放大标出，路线采集的点设为已选（与采集物点位相差 5 px 以内视为同一个点）。右上角列出路线文件、起点传送、导航段数、采集点数、产物与特殊结构。再次单击同一条路线可恢复原路线的采集点。

各段的展开起点：段前有 `MapLocateAssertLocation` 时取断言框中心；没有时，上一段终点离本段首点 30 px 以内则接着上一段展开（如乘升降索），否则从本段首点展开（如乘滑索）。

打开后照常框选增减采集点，生成按钮变为 `重新生成 <路线 id>`，预览列出相对原路线新增与移除的采集点数，与起点不连通的点同样排除在外。`写入任务` 用生成的路线替换原路线：

- 采集物种类不变时沿用原 id，只覆盖路线文件；
- 采集物种类变化时按命名规则换成新 id，删除原路线文件，在登记表中原位替换，再重新生成任务注册。

生成的路线是单段结构。原路线含多段导航、`RUN` / `INTERACT` 路点、重复采集或其他节点时，确认框会列出这些不再保留的内容；仓库中其他文件（测试用例、各资源包的覆盖文件）引用了将被移除的节点时，确认框逐个列出，需同步修改。

`删除路线` 删除路线文件、从登记表中移除并重新生成任务注册，确认框同样列出会失效的外部引用。

## 排序

排序依据步行距离：两点之间按一段 `NAVMESH` 交由运行时规划，取规划结果的折线长度，规划方式与路线展开一致，因此隔水或隔断崖的两点不会因直线距离近而相邻。

为减少规划次数：

1. 直线距离 20 px 以内的点归为一簇。簇与簇之间按步行距离以最近邻加 2-opt 排序，2-opt 仅在直线最近的若干簇之间尝试；簇内按直线最近邻排序。
2. 直线距离是步行距离的下界，排序时用于剔除无需规划的点对；直线距离小于 12 px 的两点直接按直线计。
3. 起点在距所选采集物最近的 3 个传送点中选取首段步行距离最短者，全程只排序一次。

与起点不连通的采集物（隔水、断崖或需从其他传送点进入）以红圈标记并排除在路线外，可另行生成路线。navmesh 包或虚拟禁区表变化后，步行距离自动重新计算。

## 生成结果

路线文件与现有路线同构：`Start` 进入传送点、`AssertLocation` 断言到达、`Goto` 执行 `MapNavigateAction`。`path` 以 `ZONE` 开头，采集点写作 `[u, v, "COLLECT" | "DIG", true]`。以下采集点前插入一个带 `target_deck_y` 的 `NAVMESH`，由运行时规划前往，其余采集点直线前往：

1. 首个采集点；
2. 与上一点相距超过 15 px（含高度折算）的采集点。现有手写路线中采集点之间直走的段最长 13.1 px，更远的段均依赖录制路点或 `NAVMESH`；
3. 与上一点之间需要绕行（步行长度明显长于直线）的采集点，对 12–15 px 之间的段实测判断。

`写入任务` 新建路线文件，在路线登记表中追加该路线，再按登记表重新生成任务注册：

| 文件 | 内容 |
| --- | --- |
| `assets/resource/pipeline/AutoCollect/<地区>/<路线 id>.json` | 新路线文件 |
| `tools/AutoCollectRoute/routes.json` | 路线登记表，追加一条 |
| `assets/resource/pipeline/AutoCollect/Dispatch.json` | 目标库存预判、调度循环、各产物的调度节点、各路线的执行与失败提示节点 |
| `assets/tasks/AutoCollect.json` | 各地区的产物选项、目标库存输入与门控表达式 |
| `assets/locales/interface/*.json` | 五种语言的产物名、路线名、失败与跳过提示 |

路线 id 由地区、各产物的 PascalCase 英文名与序号依次拼接而成，多种产物按 `items` 的登记顺序全部拼上，序号在同一前缀下递增。例如武陵已有 `WulingCosmagaric1` 时，再生成一条星门菌路线得到 `WulingCosmagaric2`；同时采血菌与武陵石的路线是 `WulingBloodcapWulingstone1`。

生成的路线需经实机运行确认。

## 路线登记表

任务的产物选项、调度节点与文案均由 `routes.json` 生成，生成的文件不要手改。手写或修改登记表后执行：

```powershell
uv run autocollect-route generate
```

| 字段 | 说明 |
| --- | --- |
| `routes[].id` | 路线 id，与路线文件名、节点前缀 `AutoCollect<id>` 一致 |
| `routes[].region` | 地区，`ValleyIV` 或 `Wuling`，决定路线文件所在目录和所属的地区选项 |
| `routes[].items` | 路线覆盖的产物 id；覆盖多种产物时，勾选其中任一种都会执行，一轮只执行一次 |
| `default_limits` | 产物的默认目标库存；未列出的稀有产物取 32，常规产物取 0（始终运行） |

任务界面按产物勾选，同一产物名下有多条路线时依次执行。目标库存模式下，每种产物在开跑前按仓库库存判断一次，未达目标就执行其名下全部路线。
